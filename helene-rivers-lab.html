About this lab ·

Both views use the same rivers (NHDPlus, drawn upstream to downstream) and the same USGS measured flow. Line width shows how much water; arrows move faster when a river carries more than its usual flow. Arrow speed is a drawing, not the real speed of the water.

The 2D arrows are Esri's own animation, drawn by the map engine. In 3D the SDK has no animated line symbols yet, so the app moves the chevrons itself, as it does for the wind streaks.

The 3D view follows the 2D view when "Link views" is on.
